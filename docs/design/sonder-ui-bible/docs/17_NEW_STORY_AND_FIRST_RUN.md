# 17. New Story and First Run

## Goal

A user reaches a meaningful Scene without first learning Sonder's internal
model. New Story uses the Atmospheric Workbench language from first paint; it
does not become a large-card marketing wizard.

## Entry

New Story belongs to Library lifecycle and may be launched from Empty Scene.
It opens a focused central workspace beneath the integrated top shelf. Toolbars
may collapse automatically while the draft is active, then restore afterward.

## Starting routes

1. **Describe a story**
2. **Use my Library**
3. **Start blank**

Present the routes as a compact connected selector or ledger with concise
descriptions. No decorative numbers, huge title type, or oversized floating
cards.

## Behavior

- Generation checks AI connectivity only when requested.
- Missing AI does not block Use my Library or Start blank.
- Back and exit preserve a recoverable setup draft.
- Optional fields are identified plainly.
- Review names every record and association that will be created.
- Final action is `Create Story`, not `Confirm`.
- Success activates the story and opens Scene.

## First Scene

Open with the standard atmospheric canvas, stable composer, and default module
arrangement. Underconfiguration may appear as a concise module or inline next
step; do not cover the story with a large onboarding modal.

## Authentication and guest entry

Sign-in, host setup, and guest join use the same fonts, 4 px material, compact
spacing, and restrained atmospheric field. Forms use enough opacity for trust
and readability. Security, cooldown, and lockout behavior remain runtime-owned.

Guest Scene uses the same workbench composition with unavailable host modules
absent from the Widget Shelf rather than displayed as dead controls.
