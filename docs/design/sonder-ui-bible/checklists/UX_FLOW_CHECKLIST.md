# UX Flow Checklist

## Orientation

- [ ] User knows whether they are in Play, Library, or Settings.
- [ ] Current story, scope, or item is visible.
- [ ] Parent/back route is clear.
- [ ] Primary action is obvious within five seconds.

## Progressive disclosure

- [ ] New users are not forced through internal concepts.
- [ ] Advanced controls remain discoverable.
- [ ] More menus contain genuinely secondary actions.
- [ ] Frequent actions are not hidden unpredictably.
- [ ] No feature appears in multiple primary homes without reason.

## Task efficiency

- [ ] Common action is one action from context or two from a predictable destination.
- [ ] Expert shortcut exists where useful.
- [ ] Recent/pinned state reduces repeated navigation.
- [ ] Compact mode improves density without hiding meaning.
- [ ] Search preserves scope and context.

## Feedback and saving

- [ ] Saving, saved, and failure states are visible.
- [ ] Long work has a recoverable draft.
- [ ] Error explains what failed and next step.
- [ ] User work remains present after recoverable error.
- [ ] Long tasks explain background behavior and cancelability.

## Destructive actions

- [ ] Destructive actions are visually separated.
- [ ] Confirmation names the object and consequence.
- [ ] Remove from Story is distinct from Delete.
- [ ] Irreversible actions say so.

## Empty and blocked states

- [ ] Empty state explains context.
- [ ] Empty state offers a primary recovery action.
- [ ] Missing AI connection gates only AI-dependent actions.
- [ ] Offline state preserves local work where possible.
- [ ] No dead end requires a refresh.

## Completion

- [ ] Successful completion is clear.
- [ ] Result opens in the expected location.
- [ ] Back returns to preserved context.
- [ ] User is not left in an underconfigured state without guidance.
