# UX Flow Checklist

## Orientation

- [ ] Scene, Library, or Settings is obvious in the integrated top shelf.
- [ ] Current story identity is visible but not a competing switcher.
- [ ] User knows which toolbars/modules are open.
- [ ] Closed toolbars remain discreetly discoverable.

## Module control

- [ ] Title/tab clearly acts as drag surface.
- [ ] Full title strip accepts tab merge.
- [ ] Shelf rails and tab targets never ambiguously compete.
- [ ] Live preview shows exact tab/shelf order before release.
- [ ] Separate action exists for merged tabs.
- [ ] Invalid release restores origin.
- [ ] Widget Shelf is explicit removal/recovery, not an accidental drop result.

## Ownership

- [ ] Library is the only story switcher/archive.
- [ ] Settings is the canonical home for Presentation and AI Connections.
- [ ] Docked modules locate one live instance rather than duplicate state.
- [ ] Full authoring/destructive actions remain in the owning workspace.

## Story

- [ ] Composer and prose do not stretch with toolbar state.
- [ ] Draft survives navigation and recoverable errors.
- [ ] Generation/Save/Offline state is clear without decorative animation.
- [ ] Empty Scene offers Create Story and Library without a dashboard.

## Theme

- [ ] Every material control reaches its stated bounds/default.
- [ ] Canvas, palette, glass, bars, selection, frost, and ambient light are understandable.
- [ ] Invalid theme does not replace the last valid applied theme.
- [ ] Reset and persistence are visible.

## Completion

- [ ] Result appears in the expected workspace/module.
- [ ] Back restores query, selection, scroll, and arrangement.
- [ ] Errors state recovery and work preservation.
- [ ] No common task requires decoding icons or indices.
