## Audit corrections applied

- Rebuild ordinary state integration around explicit modules/events; reject `window.S`, 500 ms polling, and synthetic hidden-control clicks.
- Rebuild truthful deep routing/history, Library scopes/search/associations, Settings search/registry, per-story drafts, mobile condition access, localization integration, and extension v2.
- Preserve current engine, persistence, authentication, guest, extension-v1, language-pack, archive, and checkpoint authority.
- Treat candidate screenshots and reported passes as historical/reference evidence only.
- Delete legacy globals, DOM shims, hidden controls, dialogs, CSS, and classic host scripts only after capability closure and cutover qualification.

## Closure rule

A row closes only when its current implementation location and reproducible evidence are linked, desktop/mobile treatment is accounted for where applicable, curated-theme/accessibility coverage is complete, and any deviation is explicitly approved. Aggregate work-package success does not close individual rows.
