Layout Lab

Each place's description went to the room designer's model twice. First it sorted everything the description names: rooms, zones of a room, fixtures, open or enclosed stairs, outbuildings, open ground, ways, outdoor features, and places that are elsewhere. Then it wrote relations for what it sorted. The solver owns every coordinate. Each block gets an outline first, and every storey divides that outline into whole rectangles. Stairs stand in their rooms at the same cells on both storeys. The grounds are open ground with things standing in them. One square is a pace (0.75 m).
