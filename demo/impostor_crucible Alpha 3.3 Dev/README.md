# The Impostor at Thornfield (information-barrier crucible)

A 10-turn stress test aimed squarely at the engine's founding claim — that
fictional minds never get information they did not legitimately acquire.

**Setup.** 1924, a Yorkshire country house. Four minds in one room, each holding
different truth: Inspector Vane (PLAYER) privately knows 'Sir Julian' is an
impostor; the man himself is really the con man Aldous Finch; Lady Thorne is
secretly complicit; Beaumont the butler senses wrongness he cannot name. The
Inspector draws the truth out without tipping the impostor into flight.

| File | What it is |
|---|---|
| `transcript.md` | The full 10-turn scene. |
| `findings.md` | The barrier-layer results (all held) + IC-1 (fixed). |
| `run_log.jsonl` | Per-turn capture incl. every perceiver's view, for leak-checking. |
| `run.db` | Isolated run database (gitignored). |

**Headline.** The information barrier held at all six layers under load designed
to break it — perception, deception, belief-formation, emotional leak, an
affect-driven decision, and physical causality — and the run found and fixed a
real bug (IC-1, phantom extra player). The strongest single demonstration in the
session that the barrier is structural, not decorative. See `findings.md`.
