あなたは計画された建物を一つ読み、その各 room が何を収めているかを述べます。何も配置せず、何も測りません。エンジンが、ここであなたが述べることと、あなたの後に二度目の呼び出しが書く関係とから、建物を配置します。

建物は計画が持つとおりに与えられます。各 room の `id`、`name`、階（`level`）、何のための room か（`purpose`）、つながる room（`joins`。`outside` と記された join は建物の外の地面へ開きます）、その `stairs`、そして計画が既に名指している `fixtures` です。room は計画のもので、階段も計画のものです。どの room もそれ自身の `id` のまま保ってください。room を足したり、二つをまとめたり、ある room を別の room の一部にしたりしてはいけません。計画はどの room にもそれ自身の壁を与えています。

建物が `description` を持つときは、それがこの建物について物語自身の伝承が語っていることです。room の `purpose` はその room が何のためにあるかを名指し、description はその中に何があるかを名指します。description がその room に置く fixture、窓、zone、床の敷物をすべて、description 自身の言葉で各 room の下に挙げ、purpose が必要とする fixture もあわせて挙げてください。room、その階、つながり、階段は、description がそれをどう呼んでいても計画のものです。建物が `brief` を持つときは、それは建物がどう建っているか（各 room がどこにあり、各階段がどこを走るか）についての建築家の説明です。room も物も足しません。

各 room について次を挙げてください。
- `fixtures`: その中にある、床を占めるもの、または身体が使うものすべて。`purpose` が名指すもの、そして計画が挙げている fixture のすべてを、それぞれ挙げられている `id` のまま挙げます。床・壁・天井が何で「できているか」は room の表面であって、fixture ではありません。それぞれがどう立っているか（`mount`）を述べます。壁際かどうかにかかわらず床に立つものは `floor`。壁に作り付けたものは壁沿いの床を占めるので、これも `floor` です。壁面に固定されて床を占めないものは `hung`、上から吊るされるものは `ceiling`、別の fixture の中や上にあるものは `in <fixture id>` か `on <fixture id>` です。計画が挙げる fixture のうち、room の中に立つものではなく、階段や出入口がその room に接する場所そのものであるものは、その道が通じる room の `id` を `marks` に添えて挙げます。エンジンがそれを、その道が room に接するところに置きます。その room が目的を果たすのに欠かせないのに計画が名指していないものは、`implied` を true にして挙げます。
- `zones`: それ自身の壁を持たない room の床の一部で、何かが起きる、あるいは決まりが始まるところ。purpose がそれを与えている場合だけです。
- `windows`: purpose か挙げられた fixture が与える外への開口それぞれ。何に面しているか（`faces`）を計画自身の言葉で、そして `count` を添えます。挙げられた fixture のうち窓そのものであるものは、ここで自分の `id` を保ち、fixture としては挙げません。

各階段について、`enclosed`（扉の向こう、それ自身の階段室にある）か、room の中に上がっている開いたものかを述べ、enclosed なら `door` を述べてください。計画が `ladder` または `hatch` と呼ぶ階段は開いたものです。

建物が `grounds` を持つときは、それが計画がこの建物に与える外の場所です。建物が建つ地面、その地面を通る道、その上に立つもの、離れて建つ小さな建物。それぞれ自身の `id` のまま、何であるか（`is`）を述べてください。身体が歩き回る地面は `open`、ある場所から別の場所へ通じる地面は `way`、地面の上に立ち、身体がその前に立つ一つのものは `feature`、建物から離れて立つ、それ自身の壁を持つ場所は `outbuilding` です。拠り所となる言葉を引いてください（`why`）。

新しい項目にはすべて snake_case の `id` と、計画が書かれている言語での `name` を与えてください。同じものが複数あれば、fixture でも window でも、`count` を付けた一つの項目にし、その `name` はそのうちの一つを名指します。エンジンはそれぞれを一つのものとして置き、そのように名付けます。どの項目も、それが何であるかで名付け、誰のものかでは名付けないでください。項目の名前に入った人の名前は、そのものを見るすべての心に届きます。その人の名前を知ったことのない心にもです。どの項目も、それが拠って立つ言葉を引用します（`why`）。計画のどこにも支えのないものは挙げません。ただし `implied` のものは別です。JSON 文字列の中では二重引用符ではなく必ず一重引用符を使ってください。

JSON オブジェクトを一つだけ答えてください。
{"rooms": [{"id": "<room id>",
            "fixtures": [{"id": "<snake_case>", "name": "...", "mount": "floor|hung|ceiling|in <fixture id>|on <fixture id>", "count": 1, "implied": false, "marks": "<room id, only for a fixture that marks where a way meets this room>", "why": "..."}],
            "zones": [{"id": "<snake_case>", "name": "...", "why": "..."}],
            "windows": [{"id": "<snake_case>", "name": "...", "faces": "...", "count": 1, "why": "..."}]}],
 "stairs": [{"from": "<room id>", "to": "<room id>", "enclosed": false, "door": "<the door, when enclosed>", "why": "..."}],
 "grounds": [{"id": "<place id>", "is": "open|way|feature|outbuilding", "why": "..."}]}
