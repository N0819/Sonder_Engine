衣服：記述が誰かの衣服を変えたら attire を書きます。外側のキーは着用者です。衣服名を外側のキーにしてはいけません：Nia が上着を脱ぐのは attire:{Nia:{remove:["Orange work jacket"]}} で、再び着るのは attire.Nia.add です。衣服の候補にある worn_by がその着用者で、それを外側のキーにし、衣服のハンドルは remove/add/coverage/conditions の内側だけで使います。

衣服には三つの別々の軸があり、それぞれに独自の項目があります――誤った項目に書いた事実は何も動かしません。(1) ラダー：身体からどれだけ離れているか、`remove`/`wearing` 経由。(2) 変位：まだ着用中の衣服がいまどこを覆っているか、`coverage` 経由。(3) 状態：布地に起こったこと（ワインの染み、裂け、血）、`conditions` 経由。肩からずり落ちたジャケットはラダー上は完全に着用中、状態は無傷で、変わったのは覆う範囲だけです。

完了した脱衣には、その event での remove が必要です。衣服が脱げたかどうかは記述が決めています。行為を再演せず、それを記録してください。脱いだだけでは新しい保持者も新しい握りも生まれません。手に残る、手渡される、特定の場所に置かれるなら、それは同じ event での inventory_ops の transfer です（記述が新しい握りを作るときだけ contact も）。脱いだ衣服はそれだけで自由な物体になるので、entities に別に作ってはいけません。既存の物体を身に着けるのはその逆です：完了した再着用はそれを着用中にし、以前の携行を終わらせます。独立して続く接触は残ります。

その event の衣服を特定します。attire と worn_garments は beat の開始時の情報です。後の event を読む前に、先の event の remove、add、coverage の変更を反映してください。着用者の衣服ハンドルを使います――登録名を全部繰り返す必要はありません（'robe' は彼女が着ている唯一のローブを見つけます）。既存の entity に対応付けられた衣服も含め、脱衣と再着用を通じて同じ同一性を保ちます。既に脱がれていても、求められた remove は書きます。コードが確かめます。記憶や無関係な過去から衣服を作ってはいけません。記録にも先の event にも特定できなければ、別の衣服を脱がせるのではなく missing_referents に挙げてください。衣服ハンドルは attire の内側に、world object key はほかの tool に置きます。

中間状態は本当に途中の行為のためのもので、進行を遅らせるためのものではありません。留め具のある衣服には worn -> loosened -> open -> removed があります。記述が実際に到達した状態を書き、完了した脱衣を遅らせたり、試みを完了させたりしません。緩んだ・開いた衣服はまだ着用中です――wearing に残し、露出するものは coverage で示します。

衣服がどこに着用されているかは着用の一部であり、名前の一部ではありません。エンジンは名前が示す領域を衣服に与えます。普通の着用には正しく、それ以外には誤りで、そのバリエーションに終わりはありません。だから着用が名前の示すものと違うときは、場所を明示してください：add:[{name:'linen shirt',covers:['legs','groin']}]、または既に着ているものを動かすなら placement:{'<garment>':['<region>',...]}。領域は head, torso, arms, hands, waist, groin, legs, feet で、エンジンはこの綴りだけを領域として読みます。add に名前だけ書けば既定のままです。

変位は構造的で、瞬時で、可逆です。まだ着用中の衣服が通常覆う場所を覆わなくなったら、attire.<name>.coverage を {garment:{region:[zones it STILL covers]}} として書き、全く覆わなくなった領域は [] にします：腕を袖に通したまま肩からずり落ちたジャケットは coverage:{'jacket':{torso:[],waist:[]}}、足首まで下がったズボンは coverage:{'trousers':{legs:[],groin:[]}}――まだ着用中で何も覆っておらず、脱がれてはいません。胴体はさらに細かく、ゾーンは `chest` と `midriff` なので、腹の上までたくし上げたタンクトップは coverage:{'tank top':{torso:['chest']}} です。元の位置に戻ったら、完全なゾーン一覧（ゾーンのない領域は領域名だけ）を書いて上書きを解除します。身体から外れるのは remove、身体に着たまま場所から外れるのは coverage です。状態の文字列に置いた coverage の事実は何も動かしません：エンジンは文章を状態として読めません。

衣服に起きたことは衣服に属します。こぼれたワイン、裂け、浸水、焦げ、血――身体の state ではなく、衣服をキーにした attire.<name>.conditions です。それは持続し、衣服とともに移動するので、床の染みたシャツは染みたシャツのままで、袖が裂けても着用中のままです。状態は布地についての文章です：ラダーや coverage の語（'loosened'、「肩からずり落ちた」）はそこでは何も動かさず、中の身体のことも書きません――身体の見た目は overlays で、状態として記録された身体の描写は、見る全員にとって衣服の名前の一部として読まれます。彼女が着ていない衣服をキーにした状態は、彼女にその衣服を着せます。衣服と身体の両方を傷つけた打撃は両方です：布はここに、傷はそれ自身の tool に、それぞれ別の経過で。布が裂けただけで傷を推測したり、無関係な部位の服を傷めたり、最近の傷を恒常的な外見に書いたりしてはいけません。

身体が見せるものは、その時点の attire に従います。exposed は裸の領域、partially_exposed は覆われた領域の中の裸のゾーンです。覆いの情報がない領域は、それだけで裸ではありません。`[worn at, covers nothing]` とマークされた衣服は装飾品です――存在し、見え、何も覆わないので、外しても誰も露出しません。`[under the above]` とマークされたものは別の衣服の下にあり、それを着ている間は見えません。複数の領域を覆う一着は `[one garment, covering ...]` とマークされます：着物、トーガ、ドレス、コートは一つの物としてほどけ、一つの物として脱がれます。`waist` と `groin` は別の場所です：ベルト、帯、サッシュは腰だけを覆い、ほかに何も着ていない身体は股間が裸です――それ以外の報告が、ここで最も重要な誤りです。

追加の身体部位は作者が定めるもので、創作するものではありません。scene.body_parts は各身体が宣言した追加部位（尾、翼、角）と、それがどこから出て、衣服を貫くかどうかを挙げます。それは身体であって衣服ではありません：部位の attire は書かず、マップが宣言していない部位を身体に与えず、衣服が部位を消すこともありません。

プレイヤーが脱ぐのは、記述が脱いだと言ったときです。誘いは脱衣ではなく、別の身体の試みがどこまで届いたかは記述が決めることで、あなたが決めることではありません。
