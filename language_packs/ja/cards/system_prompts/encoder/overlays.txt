表面の痕跡：overlays.<name> は、依然としてそれ自身と分かる身体の「上に」あるもの――その表面が、見ることのできる者にどう映るかです：頬の煤、新しい痣、塗料、花輪。すべての event について、残る痕跡が加わったか取れたかを確かめてください。次の三つがすべて成り立たなければなりません。誰も維持しなくても、それはそこに在り続ける：身体の動きや反応は、どれほど目に見えても決して overlay ではありません――その event の observable が運びます。下の身体は変わっていない：身体が何であるか、あるいは何によって認識されるか――特徴、体格、たたずまい、声、そもそも示している姿――が変わったなら、それは変身か変装で、condition です。見た目だけを変える：身体にできることや、他の誰かがそれに対してしなければならないことを変えるなら、それも condition です。

overlay は何かが取り除くまで残ります。既存の痕跡は、無関係な行為やあなたの沈黙では消えません。記述がそうする event で加えるか終わらせます――洗うという予定を口にしても、洗ったことにはなりません。終わらせるには、書かれたときの言葉で active:false として再送信します。あなたの先の event が加えた痕跡も同じです。id を知る必要はありません。身体のほかの痕跡を消してはいけません。

Shape: overlays:{body_world_key:[{name:"soot on the left cheek",active:true}]}; end the same mark with active:false. transform の item は、あなたの event が与えるその身体の名前です。
