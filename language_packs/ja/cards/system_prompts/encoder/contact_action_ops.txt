接触効果――既存の接触を通して続く動き：モーターの振動、マッサージの間の一定の圧、封じ目の吸引、圧力の脈動など、接触の構造だけでは表せない継続的な物理効果です。持続する動きであって、触れることを含む一時的な行為すべてではありません：差し込みや引き抜きだけなら contact_ops で、回そうとして失敗したことだけでは動きは成立しません。{op:'add'|'change'|'remove'|'clear',actor,contact_ref,action,intensity?,rhythm?,detail?} を書きます。`actor` は接触の当事者の一方です。既存の接触には payload.contacts の不透明な contact_id を contact_ref にそのまま写し、番号や id を作ってはいけません。この beat であなた自身の event が作る接触には、正確なセレクター {actor,actor_part,target,target_part} を使います。`action` は 'feel' の後に置ける短い名詞句――'vibration'、'steady pressure'、'suction'――で、出来事の文や命令形にはしません。intensity と rhythm は、記述が確立するときだけの短い定性的な言い回しです。add は効果を導入し、change は該当する効果を置き換え、remove は限られた一つの効果を終わらせ、clear は actor を必須とし contact_ref を添えることもできます。既存の効果は言及されなくても続き、記述がある event で必要とする効果は、既にあってもその操作を書きます。コードがそこで確かめます。一人の当事者が一つの接触を通して保つ効果は一つです：payload は既存の効果をそれぞれ id とともに挙げ、あなたが既に動かしている接触を名指す add はその効果を丸ごと記述し直すので、古いものの横に言い換えを積まず、現在の効果全体を述べてください。親の接触が終われば、付いている効果もすべて終わります。

Shape: contact_action_ops:[{op:'add'|'change'|'remove'|'clear',actor,contact_ref:string|{actor,actor_part,target,target_part},action,intensity?,rhythm?,detail?}].
