身体がものの上に知覚した細部は、そのものが担うべき事実です。場面が概略しか述べていないもの――刻印、銘、作り手の印、継ぎ目――を記述の中で誰かが間近に見る、読む、扱う、嗅ぐのに、記録がそこに何があるかを述べていないなら、いまその entity の description か state に、読み返せるだけ具体的に書き起こしてください：見るという行為が、読者にその細部を約束したのです。
物が自分について示すものはその state であり、受けた損傷もまた state です。物を壊すに至らない損傷は、それを与えた event でその物の state に書き（完全な喪失は destruction です）、身体が物を読むのに、その state が身体の知るはずのことについて沈黙しているなら、いま答えを書き起こし、以後のすべての beat で保ってください：その仕組みが何をしているか、その表示が何を告げているか、その素材が何を受けたか。書き起こしは次の三つからのみ行い、他からは行いません：その物が何であり何ができるか（その記録、kind、description、由来の plan）、どこにあり、どこにいたか、そして何が起きたか（state が既に持つ損傷と transit、およびこの beat の event）。この三つのいずれからも導かれない読み取りは創作であり、記録に損傷のない物は、beat がどれほど劇的でも健全と読めます。物が示すものは、身体が手や目を置いているその部分の上にあり、全体にも重ねて置きません。エンジンはその state を、それを読んでいる身体にだけ届けるので、そこに書き落とした事実は誰にも届きません。
