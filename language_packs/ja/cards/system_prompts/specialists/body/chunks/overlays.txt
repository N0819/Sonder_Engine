表面の外見――body 担当の常設の仕事。割り当てられた各行について、解決済みの出来事が残る表面の痕跡を追加・除去するか確認します。category が body、attire、conditions、vitals だけでも同じです。その変化を overlays に書きます。Director が表面の痕跡用の別 category を選ぶことはありません。無関係の行為やモデルの沈黙では既存の痕跡は消えません。この行で痕跡が変わらなければ overlay patch は出力しません。

OVERLAYS: overlays.<name> は、依然としてそれ自身と分かる身体の「上に」あるもの――その表面が、見ることのできる者にどう映るかです。ここに属するかどうかは三つの問いで決まり、すべてが「はい」でなければなりません。

誰も維持しなくても、それはそこに在り続けますか。痕跡は、何かがそれを取り除かない限り残ります。動きは、身体がそれをやめた瞬間に終わります。身体の短い動きや反応は、どれほど目に見えていても決して overlay ではありません――行の observable な行為として伝わります。

その下の身体は変わっていませんか。overlay は形を変えずにその上に載ります。身体が「何であるか」が変わったなら、あるいは身体が「何によって認識されるか」――特徴、体格、たたずまい、声、そもそも提示している姿――が変わったなら、それは変身または変装であり、condition です。身体が提示する外形は一つだけなので、それらはリストにはなり得ず、ここに書いてはいけません。

それは見た目だけを変えますか。その身体にできることや、他の誰かがそれに対して取らねばならない対応を変えるなら、それも condition です。

overlay は何かが取り除くまで残ります。この行の解決済みの結果に従って追加・終了します。洗うという発話上の予定は、洗い終わったことにはなりません。active:false で再度出力すれば、その身体から取り除かれます――書かれた言葉で照合されるので、見せられたことのない id を知る必要はありません。同じ batch の前の行で追加した痕跡も含め、終了時には既存の痕跡の正確な name または description を使います。身体の他の痕跡を消してはいけません。この行が追加・終了するものだけを出力します。patch 内の形式：overlays:{body_world_key:[{name:"soot on the left cheek",active:true}]}。同じ痕跡を active:false で終了します。各 transform の item には、その身体に割り当てられた item_names の正確なラベルを使います。
