着衣は既存物体の携行方法も変えます。完了した再着用は worn 関係を作り、古い自由物体としての支持用の握りを終了します。独立した接触は残ります。脱いだ衣服を保持・手渡し・特定の場所に配置する場合、assigned_hands に objects がなければ result.required_channels に "inventory_ops" を要求します。脱衣だけでは新しい保持者を指定できません。新しい接触や意図的に続く接触には typed contact operation が必要で、必要なら "contact_ops" を要求します。元の衣服の同一性を保ってください。co_hands は担当の割り当てではありません。

attire の外側のキーは着用者です。衣服名を外側のキーにしてはいけません。Nia が上着を脱ぐ例：patch:{attire:{Nia:{remove:["Orange work jacket"]}}}。再び着る場合は attire.Nia.add を使います。item はこの変換が扱う物を示しますが、チャネルの形を変えません。衣服の候補にある worn_by を着用者のキーとし、衣服のハンドルは remove/add/coverage/conditions の内側で使ってください。
衣服の追跡：ビートで誰かの衣服が変わった場合はstate_diff.attireに記録してください。衣服には三つの別々の軸があり、それぞれに独自のチャネルがあります――誤ったチャネルに書くと何も動きません。(1) ラダー：身体からどれだけ離れているか、`remove`/`wearing`経由。(2) 変位：現在着用中の衣服がどこを覆っているか、`coverage`経由。(3) 状態：布地に起こったこと（ワインの染み、裂け、血）、`conditions`経由。肩からずり落ちたジャケットはラダー上は完全に着用中、状態は無傷、変化は覆う範囲のみです。
衣服がどこに着用されているかは着用の一部であり、名前の一部ではありません。エンジンは名前が示す領域をデフォルトに設定しますが、これは普通の着用には正しく、それ以外には誤りです――頭に下着、胸にベルト、帽子代わりの植木鉢、ズボンとして着たシャツ、腕に履いたズボン。変化は無限で語彙リストでは網羅できないため、着用が名前の示すものと異なる場合は必ず場所を伝えてください：add:[{name:'linen shirt',covers:['legs','groin']}]、またはplacement:{'<garment>':['<region>',...]}で既に着用中のものを移動。領域は head, torso, arms, hands, waist, groin, legs, feet の八つで、エンジンはこの綴りだけを領域として読みます――訳した語は領域名ではなく、黙って破棄されます。`add`に名前だけ書くとデフォルトのままなので、デフォルトが誤りの場合のみ明示してください。
完了した脱衣にはこの行の remove が必要です。衣服が脱げたかは Director が解決済みです。その裁定を記録し、行為を再演しません。手に残る、手渡す、指定場所に置く場合は上記の通り不足する inventory 担当を要求します。脱衣だけでは新しい保持者や握りは成立しません。
この行の衣服を特定します。attire と worn_garments は開始時の情報です。先行行の remove、add、coverage 変更を反映してからこの行を扱います。既知の着用者の衣服ハンドルを、対応付けられた既存物体の識別も含めて使い、脱衣と再着用を通じて維持します。既に脱がれていても要求された remove 操作を出し、コードに変化のない不在を検証させます。記憶や無関係な過去の文章から衣服を作りません。開始記録でも先行行でも特定できなければ、別の衣服を脱がせず no_referent を返します。
中間状態は本当に途中の行為のためであり、進行を遅らせる指示ではありません。留め具のある衣服には worn -> loosened -> open -> removed があります。この行で解決された状態を使い、完了した脱衣を遅らせたり、途中の試みを完了させません。緩んだ・開いた衣服はまだ wearing に残し、露出は構造化された coverage で示します。脱いだ衣服は自動的に自由な物体となるため、entities に別のコピーを作りません。attire 内は衣服ハンドル、他 channel は world object key とし、提供された対応付けを使います。任意の object id が衣服を特定するわけではありませんが、その衣服に既に対応付いた entity は脱衣と再着用を通じて同じ識別を保ちます。
位置ずれは構造的で瞬時かつ可逆的です。まだ着用中の衣服が通常覆う場所を覆わなくなった場合――肩からずり落ちたジャケット、腰まで上げられたスカート、足首まで下がったズボン――は、attire.<name>.coverageを{garment: {region: [zones it STILL covers]}}として書き、全く覆わなくなった領域は[]で示します。例：腕は袖に通したまま肩からずり落ちたジャケット＝coverage:{'jacket':{torso:[],waist:[]}}；足首まで下がったズボン＝coverage:{'trousers':{legs:[],groin:[]}}――まだ着用中で何も覆っていないが脱がれてはいません。胴体は細かく、ゾーンは`chest`と`midriff`なので、腹部より上にたくし上げられたタンクトップはcoverage:{'tank top':{torso:['chest']}}となります。位置ずれは一連の動作で起こり、元に戻すのも一連の動作です。衣服が元の位置に戻ったら、オーバーライドを解除するために完全なゾーンリスト（ゾーンのない領域は単なる領域名）を書いてください。状態文字列だけにcoverageの事実を残してはいけません。エンジンは文章を状態として読み取れず、ナレーションが覆っていないと言っていても台帳上は覆ったままになります。身体の外は`remove`、身体上で場所から外れているのは`coverage`です。
衣服に起きたことは衣服に属します。こぼれたワイン、裂け、浸水、焦げ、血液：これらは身体の`state`ではなく、attire.<name>.conditionsに衣服をキーとして入れてください。変化があるまで持続し、脱がれた際にも衣服と共に移動します。つまり、床にある染みのついたシャツは染みのついたシャツのままです。損傷は脱衣ではありません――袖が裂けてもまだ着用中です。状態は布地に関する文章であり、状態語ではありません。'loosened'や「肩からずり落ちた」を状態に書いても何も動かず、はしご状の破れやcoverageのチャンネルで管理される事実です。
解決された打撃が衣服と身体の両方を傷つけた場合、両方を記録します。布の損傷は attire.<着用者>.conditions、身体の負傷は各 channel の定めに従い vitals.injury、conditions、overlays で扱います。これは経過の異なる別の効果です。傷が治っても裂けたコートは裂けたままであり得ます。Director の実際の結果と既存の世界法則に従い、布が裂けただけで負傷を推測したり、無関係な部位の服を傷つけたりしません。最近の負傷を恒常的な外見へ書き込みません。
身体の露出はその時点の構造化された attire に従います。exposed は裸の領域、partially_exposed は一部だけ裸の zone です（compact attire は torso:chest>tank top/midriff>bare のように示します）。これは先行する衣服操作で変わる開始時の事実です。緩んだ・開いた衣服は着用中であり、構造化された coverage が定めた部分だけを露出します。カバー情報が未記述の領域を裸とみなしません。Director が定めた衣服変更を記録する代わりに、露出を創作・裁定しません。
`[worn at, covers nothing]`とマークされた衣服は装飾品です――リボン、ネックレス、指輪。存在し目に見えますが何も覆いません：その下の領域は裸であり、外しても誰も露出しません。`[under the above]`とマークされた衣服は別の衣服の下にあり、その衣服が着用されている間は見えません。
一着の衣服は複数の部位を覆うことがあり、リストに記載されている場所に`[one garment, covering ...]`とマークされます。着物、トーガ、ドレス、コートは一つの物として扱います：一体として脱がれ、それを脱ぐと同時に覆っていたすべての部位が露出します。袖や裾を別々に脱ぐ別の衣服として扱わないでください。
`waist`と`groin`は異なる場所です。ベルト、帯、サッシュは腰部のみを覆います — 他に何も身に着けていなければ股間は裸であり、それ以外の報告はここで最も重要な誤りです。
追加の身体部位は創作されるものであり、発明されるものではありません。scene.body_partsが存在する場合、それぞれの身体が宣言した追加部位（尾、翼、角など）と、それがどこから出ているか、衣服を貫通するかどうかを記載します。これらは物理的に実在し、その部位名は有効な接触点（actor_part/target_part）です。衣服を着ている間も貫通する部位は外に出て見え続け、衣服はそれを消しません。このマップで宣言されていない追加部位を身体に与えず、身体部位に対して衣服の記録を書かないでください — 部位は身体であり、衣服ではありません。
条件は衣服を説明するものであり、それを着ている身体を説明するものではありません。肩の裂け目、濡れ通り、留め具の外れ、汚れ — 布に起きたことです。身体そのものの見た目は`overlays`であり、一つの記述が両方のチャンネルで正しい答えになることはありません。条件として記録された身体の描写は、その人を見る全員に衣服の名前の一部として描画され、台帳に残り続けます。

形式：attire:{name:{add:[],remove:[],replace:null,state:null,conditions:{garment_name:'what just happened to it'},coverage:{garment_name:{region:[zones it STILL covers] or [] for a region it no longer covers}}}} — 衣服の識別子は登録名を繰り返す必要はありません（'robe'は彼女が着ている唯一のローブを見つけます）、そして彼女が着ていない衣服に紐づく条件は彼女をその衣服で着飾らせます。
プレイヤーが脱ぐのは、権限のある行為がそう定めた場合です。Director が解決した行為と権限に従います。誘いだけで脱衣にはならず、別の行為者の試みがどこまで成功するかを specialist が選ぶこともありません。この行で実際に成立した衣服変更を記録します。
