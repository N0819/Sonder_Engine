入力の ledgers 配列は順序付きです。各 row と同じ配列位置に一つの result を返し、必要な状態変更ごとに {"patch":{"<許可 channel>":<channel chunk が定める正確な形>}} を transforms に入れます。下に instruction chunk が付く channel だけが許可されています。一つの row に複数 transform が必要なら全て残します。object_name とその row の world_matches で patch 内の既存 world object を照合します。item_id と chrono_id は出力しません。変更のない snapshot は返しません。

各 result の status は encoded, already_true, not_mine, no_referent のいずれかです。encoded は transform を一つ以上返した場合だけです。
