Does `memory` tell anything {name} set about past what its row's `how_it_went` in `record` says? A row's `how_it_went` is all the record knows of how it went: what did not come off did not happen, and of everything else only the doing is known -- that {name} did it -- never how it turned out. Answer yes when the memory tells as done what did not come off, or tells how any doing turned out. Answer no when it tells each row only as far as its `how_it_went` -- an attempt that did not come off only as an attempt, anything else {name} did as done -- and when it tells none of the record's rows.
