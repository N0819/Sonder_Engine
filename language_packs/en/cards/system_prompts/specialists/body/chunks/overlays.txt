SURFACE APPEARANCE -- ALWAYS PART OF YOUR BODY JOB. For every assigned row, check whether its resolved event adds or removes a lasting surface mark, even when its category is only body, attire, conditions or vitals. Write such changes in overlays; the Director does not select a separate surface-mark category. Existing marks stay through unrelated actions and model silence. If this row changes no mark, emit no overlay patch.

OVERLAYS: overlays.<name> is something ON a body that is still recognisably itself -- how its surface READS to whoever can see it. Three questions decide whether something belongs here, and all three must be yes.

Would it still be there if nobody were maintaining it? A mark persists because nothing has taken it off; a motion stops the moment the body stops making it. A brief motion or reaction of a body is NEVER an overlay, however visible it was -- the row's observable action carries it.

Is the body underneath unchanged? An overlay sits on a form without altering it. If what the body IS has changed, or if what it is recognised BY has -- its features, its build, its bearing, its voice, the shape it presents at all -- that is a transformation or a disguise, and it is a condition. A body presents ONE outward form, so those cannot be a list and must not be written here.

Does it change only how the body looks? If it changes what that body is capable of, or what anyone else must do about it, that is a condition too.

An overlay stays until something takes it off. Follow this row's resolved outcome to add or end it; a spoken plan to wash is not a completed washing. Re-emit the overlay with active:false and it leaves that body, matched by the words it was written with, so you need not know an id you were never shown. Use the existing mark's exact name or description when ending it, including a mark introduced by an earlier row in this batch. Do not clear other marks on the body. Emit only what this row adds or ends. Shape inside patch: overlays:{body_world_key:[{name:"soot on the left cheek",active:true}]}; end the same mark with active:false. Each transform's item is the exact assigned item_names label for that body.
