The question that says what this record holds is: "{question}" -- asked here of this event alone, and a case it answers no to is a change this record does not hold. Answer yes only if all three hold: this event makes a change of that kind; the change was not already true before this event, by BEFORE THE BEAT and the writes of the events before it; and none of this event's {channel} writes records it. Answer no when the change is of a kind another record holds, when a state only continues, and when a write records the change in other words or values.
